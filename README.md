## Descripción del Proyecto

**Transportes Orellana** es una empresa dedicada al servicio de fletes y transporte terrestre de carga pesada (6 a 10 toneladas) con cobertura en El Salvador, Guatemala y Honduras.

Este proyecto consiste en el análisis, diseño e implementación de una **aplicación web empresarial** construida bajo el patrón arquitectónico **MVC**, diseñada para reemplazar los registros manuales en papel y las hojas de cálculo dispersas. El sistema centraliza la gestión de clientes, control de motoristas, flota de camiones, trazabilidad de fletes y cálculo automatizado de utilidades netas por viaje.

### Objetivos Clave
* Digitalizar el registro y seguimiento de las solicitudes y servicios de flete.
* Centralizar la información relacionada con clientes, motoristas, unidades de transporte y viajes.
* Facilitar el registro de los gastos asociados a cada servicio de flete.
* Proporcionar información consolidada mediante reportes que apoyen el seguimiento de las operaciones y la toma de decisiones.

## Stack Tecnológico y Arquitectura

* **Backend:** ASP.NET Core MVC (C#) con arquitectura desacoplada en controladores dedicados.
* **Persistencia y ORM:** Entity Framework Core.
* **Base de Datos & Cloud BaaS:** Supabase (PostgreSQL) para persistencia relacional y almacenamiento de archivos (PDFs y CVs).
* **Frontend:** Razor Views y Bootstrap.
* **Seguridad:** ASP.NET Core Identity y cifrado de conexiones mediante SSL/HTTPS.
* **Control de Versiones y Metodología:** Git/GitHub bajo marco de trabajo **Scrum** con prototipado evolutivo.
